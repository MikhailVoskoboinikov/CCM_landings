# Лендинги учебного центра ЦКМ

Страницы курсов BLS, «Первая помощь» и «Первая помощь детям» для Узбекистана и Кыргызстана.

```bash
cd landing
npm install
npm run dev        # http://localhost:4321
npm run build      # статичная сборка в landing/dist
```

- `/uz/bls`, `/kg/first-aid-kids` — страницы курсов
- `/playground/uz/bls` — стенд со всеми вариантами блоков, комментариями и вопросами к ЦКМ

Переменные окружения (`landing/.env`):

- `PUBLIC_LEADS_ENDPOINT` — адрес приёма заявок; без него форма работает в режиме макета
- `PUBLIC_SHOW_MARKS=1` — подсвечивать пометки «уточнить у ЦКМ» в сборке (для тестового стенда)

Устройство проекта и договорённости — в [CLAUDE.md](CLAUDE.md).
